# 管理接口权限说明

## 📋 概述

管理接口的权限验证是可选的，取决于是否配置了 `ADMIN_SECRET` 环境变量。

## 🔐 权限机制

### 何时需要权限？

**如果设置了 `ADMIN_SECRET` 环境变量**，以下接口需要权限验证：

1. **结算接口** - `POST /api/admin/settle`
2. **奖状配置接口** - `GET/POST/DELETE /api/admin/cert-config`
3. **奖状底图上传接口** - `POST /api/upload/cert`

### 何时不需要权限？

**如果没有设置 `ADMIN_SECRET` 环境变量**，所有管理接口都可以直接访问，无需权限验证。

## 🔑 如何使用权限

### 1. 设置环境变量

在 `.env` 文件或 `docker-compose.yml` 中设置：

```bash
ADMIN_SECRET=your-admin-secret-change-this-in-production
```

### 2. 调用接口时携带密钥

在请求头中添加：

```
Authorization: Bearer your-admin-secret-change-this-in-production
```

### 3. 示例

```bash
# 使用 curl 调用结算接口
curl -X POST \
  -H "Authorization: Bearer your-admin-secret-change-this-in-production" \
  http://localhost:3000/api/admin/settle?week=50&year=2025
```

## 📝 注意事项

1. **定时结算任务**：每周一 21:00 的自动结算任务不受权限限制，会正常执行
2. **管理页面**：如果设置了 `ADMIN_SECRET`，管理页面需要输入密钥才能使用
3. **安全性**：生产环境建议设置 `ADMIN_SECRET` 以防止未授权访问

## 🛠️ 配置建议

- **开发环境**：可以不设置 `ADMIN_SECRET`，方便测试
- **生产环境**：建议设置 `ADMIN_SECRET`，使用强密码
