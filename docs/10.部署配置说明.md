# 10. 部署配置说明

## 环境变量配置位置

### 开发环境

**位置**：项目根目录 `.env` 文件

```env
DATABASE_URL="mysql://cc:200871@139.196.30.138:3306/weightdb"
JWT_SECRET="your-secret-key"
OSS_ACCESS_KEY_ID="..."
OSS_ACCESS_KEY_SECRET="..."
OSS_BUCKET="weighin-media"
OSS_REGION="oss-cn-wuhan-lr"
OSS_ENDPOINT="https://oss-cn-wuhan-lr.aliyuncs.com"
```

**使用时机**：本地开发时，Next.js 自动读取 `.env` 文件

---

### 服务器部署（Docker Compose）

**位置**：项目根目录 `docker-compose.yml` 文件

```yaml
environment:
  - DATABASE_URL=mysql://cc:200871@139.196.30.138:3306/weightdb
  - JWT_SECRET=your-secret-key
  # ... 其他环境变量
```

**使用时机**：在服务器上使用 `docker-compose up` 启动容器时

**注意**：`docker-compose.yml` 已加入 `.gitignore`，不会提交到代码仓库

---

### 云效部署（推荐）

**位置**：云效部署平台的环境变量配置

**方式一**：云效密钥管理
- 在「应用管理」→「密钥管理」中创建密钥
- 在「部署」步骤中选择「使用密钥」

**方式二**：容器服务（ACK）控制台
- 在部署配置的「环境变量」中添加所有变量

**使用时机**：容器启动时自动注入

**优势**：环境变量不写入镜像，更安全

---

## 配置对比

| 场景 | 配置文件 | 位置 | 是否提交 Git |
|------|---------|------|------------|
| 本地开发 | `.env` | 本地 | ❌ 否（已在 .gitignore） |
| 服务器部署 | `docker-compose.yml` | 服务器 | ❌ 否（已在 .gitignore） |
| 云效部署 | 平台环境变量 | 云效控制台 | - |

---

## 必需的环境变量

```
DATABASE_URL          # 数据库连接字符串
JWT_SECRET           # JWT 签名密钥
OSS_ACCESS_KEY_ID    # OSS 访问密钥 ID
OSS_ACCESS_KEY_SECRET # OSS 访问密钥 Secret
OSS_BUCKET           # OSS 存储桶名称
OSS_REGION           # OSS 区域
OSS_ENDPOINT         # OSS 端点地址
ADMIN_SECRET         # 管理员接口密钥
```

## 快速参考

### 本地开发
```bash
# 1. 创建 .env 文件并配置
# 2. 运行开发服务器
npm run dev
```

### 服务器部署
```bash
# 1. 上传 docker-compose.yml（包含环境变量）到服务器
# 2. 运行
docker-compose up -d
```

### 云效部署
1. 构建阶段：只构建应用代码（不包含敏感信息）
2. 部署阶段：在云效控制台配置环境变量
3. 容器启动时：自动注入环境变量

---

## 安全提示

✅ **推荐做法**：
- 环境变量通过运行时注入，不写入镜像
- 使用云效密钥管理或容器服务的 Secret 功能
- 敏感信息文件不提交到 Git

❌ **不推荐**：
- 在 Dockerfile 中硬编码敏感信息
- 将包含敏感信息的文件提交到 Git
